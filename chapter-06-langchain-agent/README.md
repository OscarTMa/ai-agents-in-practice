## 📌 Overview & Learning Objectives

This chapter shifts from individual architectural primitives into an end-to-end production-grade agent: **AskMamma**, an interactive e-commerce assistant for a digital Italian eatery (*Mammachepiada*). The agent orchestrates natural dialogue, multi-turn conversational history, structured SQL querying, semantic retrieval over certificates (RAG), and transactional API side effects (cart mutation).

By completing this module, you will understand:
1. **The Three Pillars of the LangChain Ecosystem:**
   - **Build:** Open-source core abstractions (`LangChain`, `LangGraph`) for state, prompts, chains, and agents.
   - **Run:** Deployment runtimes, stateful streaming servers (`LangGraph Platform`), and connectors.
   - **Manage:** Observability, runtime debugging, and trajectory evaluation (`LangSmith`).
2. **Out-of-the-Box Component Taxonomy:** RAG loaders/splitters, storage & indexing interfaces, schema-enforced extractors (Pydantic), and autonomous agent executors.
3. **Multi-Tool Orchestration:** Unifying structured data (SQLite catalogue), unstructured knowledge (hygiene certifications), and external HTTP REST operations (shopping cart state).
4. **Trajectory & Intermediate Step Evaluation:** Auditing whether the agent invokes the correct tools in the proper sequence without extraneous or missing steps.
5. **Conversational Frontends:** Embedding conversational agents into responsive application interfaces (Streamlit).

### 2. Multi-Modal Tool Capabilities

| Tool Interface | Target System | Data Modality | Operational Mechanism |
| :--- | :--- | :--- | :--- |
| `document_search` | Safety Documentation | Unstructured Text | Vector similarity search over chunked compliance and hygiene reports. |
| `sql_product_lookup` | Enterprise Inventory | Structured Relational (SQL) | Deterministic schema queries over products, prices, and suppliers in SQLite. |
| `add_to_cart` | Shopping Cart Backend | Transactional State (HTTP) | Emits POST requests updating session items and quantities. |

---

### 3. Agent Evaluation & Observability (LangSmith Standard)

Evaluating agents differs fundamentally from standard classification metrics:
* **LLM-as-a-Judge:** Evaluating conversational helpfulness, accuracy, and tone using a designated judge prompt scored from 1 to 5.
* **Trajectory Correctness:** Validating that intermediate tool actions match the expected sequence:
  $$\text{Score} = \mathbb{I}(\text{Actual Trajectory} == \text{Expected Trajectory})$$
* **Grounding & Faithfulness:** Ensuring facts generated by the agent strictly correlate with documents retrieved during the RAG step.
